# 潜水店值班充填台（端口 62010）

气瓶充填值班作业系统，围绕值班充填台的实际流程设计：

1. **按检验有效期分流**：登记入店时校验检验有效期，已过期气瓶只能进入「送检区」，不能占用任何当日充填位；复检合格、更新有效期后才能回到待充填队列。
2. **充填位独占**：每个充填位同时只承接一项未完工气瓶，被占用的位置不可再安排其他气瓶；未完工撤下时已录参数保留。
3. **换班交接**：换班时在充填位上的作业连同全部已录参数交给下一位值班员，单据保持「充填中」不关闭，并写入交接日志；不允许关闭后再补记。
4. **收尾判定**：收尾必须填写实测压力、O₂、He 和充填方式；压力 ±10bar、O₂/He ±1% 为目标区间，任一项超差整单进入返工。
5. **返工签字交付**：返工后重新实测，全部回到目标区间，且有复核人签字，才允许交付。
6. **记录保留**：所有单据、过程参数与交接记录保存在浏览器 localStorage，刷新或关闭后重开仍然保留；已交付单据全程只读锁定。

页面包含：当班签到 / 换班、气瓶登记分流、充填位看板与过程参数记录、收尾与返工复核弹窗、送检区、全部记录与单瓶历史、交接日志。
